EveNeed - Modern E-Commerce Web Application
==============================================
Setup Instructions:
1. Start Apache and MySQL from XAMPP Control Panel.
2. The database 'EveNeed' is configured in config/database.php.
   (Import database/EveNeed.sql if initializing for the first time).
3. Open in your browser:
   http://localhost/practice/EveNeed/EveNeed/
   or http://localhost/EveNeed/

Default Admin Credentials:
- Username: admin
- Password: 1234
- Admin Login URL: admin-login.php or admin/

Default Demo User Credentials:
- You can register a new account on register.php.
- The admin approves/activates new accounts from Admin Panel -> Users.
